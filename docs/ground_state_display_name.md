# Proposed ground-state column label

Proposed display name: **Experimental-order stability**.

The dimension tests whether the experimental magnetic order remains competitive
within the supplied cell and candidate pool, subject to DFT moment-amplitude
matching. The label does not imply an unrestricted search over supercells or
ordering wavevectors. Only display strings change: `ground_state` keys, file
names, cohorts, reference arrays and scoring remain unchanged.

This proposal is isolated in the final commit for independent review.
